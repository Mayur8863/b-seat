# Seed photo credits

Each file: resized to 1600 px on the long edge, JPEG q82 (mozjpeg), metadata removed. One-off sharp script in the tools container, `autoOrient().resize(1600, 1600, { fit: 'inside' }).jpeg({ quality: 82, mozjpeg: true })`; no download runs at seed time.
