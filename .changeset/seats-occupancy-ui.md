Owners can now see each seat's state today (vacant, occupied by you with a private note, or booked by a renter), select several seats with the keyboard (Space, Shift+Space for a range, or Select all), mark them occupied for a date range, and mark a seat vacant or remove an upcoming mark. A refused mark lists each seat's booked dates and existing marks, and nothing is created.
