New "Find a space" page at `/find`: search spaces by country, city and area (with suggestions), start date, pass, slot and utilities. Filters start from your saved location and live in the URL, so results can be shared and the back button works. Each result links to the space, and "Back to results" on the space page returns to the same search. The navigation and dashboard now link to it.
